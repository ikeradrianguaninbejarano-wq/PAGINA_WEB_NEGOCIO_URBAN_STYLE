# Imágenes de producto

Los archivos SVG incluidos son ilustraciones provisionales hechas para este proyecto. Puedes reemplazarlos por fotografías locales conservando sus nombres y rutas, o actualizar `image` en `data/productos.json` y los `src` del catálogo en `index.html`.

Usa imágenes optimizadas y escribe un texto `alt` breve que describa el producto. No se necesitan servicios ni APIs externas.
